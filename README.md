# To-Do List App

### 🔗 **Live Site:** [nasif-zaman38.github.io/todo-list-app](https://nasif-zaman38.github.io/todo-list-app/)

### 📝 About the Project

A simple To-Do List application built with HTML and JavaScript to manage daily tasks. Users can add new tasks, mark tasks as completed, delete tasks, and track the total number of tasks.

### 🛠️ Technologies Used

- HTML
- JavaScript
